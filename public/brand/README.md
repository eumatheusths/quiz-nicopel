# Logos oficiais da Nicopel

Coloque aqui os arquivos originais fornecidos pelo Marketing da Nicopel, com
exatamente estes nomes:

| Arquivo                     | Uso                                            |
| --------------------------- | ---------------------------------------------- |
| `nicopel-logo.svg`          | Logo original, para fundos claros              |
| `nicopel-logo-branca.svg`   | Logo branca, para fundos escuros ou sobre fotos |

Enquanto os arquivos não existirem, o componente `src/components/ui/Logo.tsx`
exibe um marcador tipográfico neutro — propositalmente diferente da marca, para
que ninguém o confunda com o logo oficial. Assim que os arquivos forem
colocados aqui, eles aparecem automaticamente, sem mudança de código.

**Regras:** não redesenhar, deformar, esticar, recolorir ou recriar a logo.
Use apenas os arquivos originais. Se só houver PNG, troque a extensão nos dois
caminhos de `SOURCES` em `Logo.tsx`.
