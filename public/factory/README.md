# Fotos reais da Nicopel

Coloque aqui as fotos autorizadas do parque fabril, da linha de produção, da
equipe e das embalagens. O projeto usa estes dois arquivos:

| Arquivo         | Onde aparece                     | Proporção sugerida |
| --------------- | -------------------------------- | ------------------ |
| `hero.webp`     | Topo da página inicial           | 4:3 (≥ 1200 px)    |
| `producao.webp` | Bloco “O que a gente faz”        | 4:3 (≥ 1200 px)    |

Enquanto os arquivos não existirem, `PhotoFrame` mostra uma composição gráfica
inspirada em dobras de papel e faca de corte — nunca uma foto genérica de banco
de imagem. Ao colocar os arquivos aqui, eles aparecem automaticamente.

## Antes de subir

- confirme a autorização de uso de imagem das pessoas retratadas;
- exporte em WebP (ou AVIF) com qualidade 78–85;
- mantenha cada arquivo abaixo de ~250 KB;
- ajuste o texto alternativo em `src/app/page.tsx` para descrever a foto real.
